## Plan: Show Account List on Focus Instead of Requiring Typing

**Problem:** Currently, the account dropdown only appears after the user types something in the Search Account box. The user wants all related accounts to appear automatically when the input is focused (cursor placed inside), even before any text is typed.

**Files to modify:** 2 files

### 1. `src/components/fazai/transaction-form.tsx`

**a) Remove the empty-query guard from `filteredAccounts` (line 97):**
```tsx
// BEFORE (line 97-102):
const filteredAccounts = searchQuery
  ? accounts.filter(a => {
      const name = getAccountName(a, lang).toLowerCase();
      return name.includes(searchQuery.toLowerCase());
    })
  : [];

// AFTER:
const filteredAccounts = accounts.filter(a => {
  const name = getAccountName(a, lang).toLowerCase();
  return !searchQuery || name.includes(searchQuery.toLowerCase());
});
```

**b) Add an `isSearchFocused` state variable** (near line 39):
```tsx
const [isSearchFocused, setIsSearchFocused] = useState(false);
```

**c) Change the dropdown visibility condition** (line 292) from `{searchQuery && (` to `{isSearchFocused && (`:
```tsx
// BEFORE (line 292):
{searchQuery && (
  <div className="flex flex-col gap-1 mt-2 max-h-40 overflow-y-auto">

// AFTER:
{isSearchFocused && (
  <div className="flex flex-col gap-1 mt-2 max-h-40 overflow-y-auto">
```

**d) Add `onFocus`/`onBlur` handlers to the search Input** (line 285-290):
```tsx
<Input
  value={searchQuery}
  onChange={(e) => setSearchQuery(e.target.value)}
  onFocus={() => setIsSearchFocused(true)}
  onBlur={() => setIsSearchFocused(false)}
  placeholder={t('form.searchAccount', lang)}
  className="pl-9"
/>
```

**e) Clear search on blur** — reset `searchQuery` when focus leaves (via `onBlur`):
```tsx
onBlur={() => { setIsSearchFocused(false); setSearchQuery(''); }}
```
