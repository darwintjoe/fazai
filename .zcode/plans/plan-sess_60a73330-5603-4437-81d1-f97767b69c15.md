## Implementation Plan: Combined Welcome Setup (Owner Name + PIN Change)

### Overview
5 changes across 5 files + 1 new file. Single welcome screen: owner name first, then set a new PIN. Both required to proceed. PIN change does NOT verify old PIN — user can reuse 000000. Shows on every login until owner name is filled.

---

### Step 1: Add i18n Translation Keys
**File:** `src/lib/i18n.ts`
- Add 5 new keys to `TranslationKeys` interface and all 3 language objects (en, id, zh):
  - `setup.welcomeTitle` — "Welcome to FAZAI" / "Selamat Datang di FAZAI" / "欢迎使用 FAZAI"
  - `setup.ownerCaption` — "This Database belongs to" / "Database ini milik" / "此数据库属于"
  - `setup.ownerDesc` — "Owner name will be used when print Report" / "Nama pemilik akan digunakan saat cetak Laporan" / "所有者姓名将用于打印报表时显示"
  - `setup.ownerPlaceholder` — "Enter owner name" / "Masukkan nama pemilik" / "请输入所有者姓名"
  - `setup.setPin` — "Set your PIN" / "Atur PIN Anda" / "设置您的PIN码"

### Step 2: Create Combined Welcome Setup Component
**File:** `src/components/fazai/welcome-setup.tsx` (NEW)
- Full-screen overlay dialog (same style as UserGuide overlay)
- **Section 1 — Owner Name (required):**
  - Caption: `"This Database belongs to"` (or i18n equivalent)
  - Text input with placeholder
  - Small description: `"Owner name will be used when print Report"`
- **Section 2 — Set PIN (required, no old PIN check):**
  - Label: `"Set your PIN"`
  - New PIN input (6 digits)
  - Retype PIN input (6 digits)
  - Inline validation: show error if PINs don't match
  - User can reuse `000000` — no restriction
- **Single Save button:**
  - Disabled until owner name filled AND both PINs match
  - Saves in one step:
    - Writes `owner-name` to `settings` table
    - Updates user's PIN in `users` table (no old PIN verification)
  - On save → calls `onComplete` callback

### Step 3: Show Default PIN Hint on Login Screen
**File:** `src/components/fazai/pin-login.tsx`
- Add hint text below "Enter PIN": `"Default PIN: 000000"`
- Only on fresh install (all users have `isSystem: true`)

### Step 4: Show Welcome Setup After Login
**File:** `src/app/page.tsx`
- Add state `showWelcomeSetup`
- On mount when `isAuthenticated`: read `owner-name` from `settings`
- If empty → show `<WelcomeSetup>` overlay
- On `onComplete` → hide overlay
- Shows every refresh/relogin until owner name is set

### Step 5: Owner Name in Reports
**File:** `src/components/fazai/report-viewer.tsx`
- Read `owner-name` from settings
- PDF: show as subtitle below "FAZAI"
- XLSX: prepend row
- Filename: `{ownerName}-reportType-date`

### Step 6: Owner Name in Pinger
**File:** `src/hooks/use-pos-tracker.ts`
- Use `owner-name` as `storeName` if set, fallback to `user:${userId}`
